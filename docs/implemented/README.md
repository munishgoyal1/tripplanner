# Implemented Backlog Archive

This folder contains backlog documents whose full approved implementation is complete and validated.

## Lifecycle rule

When an item from `docs/feature-briefs-backlog/` or `docs/eng-backlog/` is fully implemented, validated, and its canonical documentation is updated, move its complete brief or backlog entry into this folder in the same completion commit. Update its status to `Shipped` or `Implemented`, record the implementation commit and validation evidence, and remove it from the active backlog index.

Do not move drafts, partially implemented foundations, UX directions awaiting selection, deferred entries, or items with outstanding must/should acceptance criteria. Those remain in their backlog folder until the whole approved scope is complete.

The archive is historical implementation truth. It does not authorize new work; approval still comes from the feature brief or engineering owner workflow before implementation begins.
