# Codex repository instructions

This repository is governed by AGENTS.md at the workspace root. Codex must follow the same rules and reporting requirements as the Copilot instructions in this repo.

Always include the final summary sections required by AGENTS.md:
- Original prompt
- Root cause (RCA)
- Summary
- Next actions
- Learning note

If the task is substantive, do not end with a bare status line. Follow the repo's structured reporting standard.
